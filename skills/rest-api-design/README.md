# REST API Design

Designs new REST APIs or reviews existing ones: resource naming, HTTP methods and status codes, pagination, versioning, and a consistent error contract (RFC 7807). Produces an endpoint table you can build from.

## Files
- `api-design.md` — the API design/review skill.

## Use it when
- You're about to create new endpoints and want them right the first time.
- Your existing API is inconsistent (verbs in URLs, random status codes, no pagination).
- You need a standard error response shape across the API.

## Invoke
```
Use @skills/rest-api-design/api-design.md to design the endpoints for a product catalog with categories and reviews
```
