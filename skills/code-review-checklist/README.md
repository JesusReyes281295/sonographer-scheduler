# Code Review Checklist

Reviews a diff, branch, or PR like a thorough senior engineer: correctness first (traced with concrete inputs), then security, tests, design, and style — producing findings ranked BLOCKER → NIT, each with a concrete failure scenario and a specific fix.

## Files
- `code-review-checklist.md` — the code review skill.

## Use it when
- Before merging a branch or opening a PR.
- You want a second pair of eyes on risky changes.
- Reviewing someone else's contribution to your repo.

```
Use @skills/code-review-checklist/code-review-checklist.md to review my current branch against main
```
