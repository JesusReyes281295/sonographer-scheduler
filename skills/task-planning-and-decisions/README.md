# Task Planning & Decisions

Turns a defined task (e.g. "build a REST API with these endpoints") into a concrete plan: technology choices, naming recommendations, folder structure, and an ordered list of verifiable steps — asking only the questions that are actually missing.

## Files
- `task-planning.md` — the planning skill.

## Use it when
- You know WHAT to build but not HOW to start or in what order.
- You want technology recommendations justified for your specific context.

## Invoke
```
Use @skills/task-planning-and-decisions/task-planning.md — my task: create a REST API for managing orders
```
