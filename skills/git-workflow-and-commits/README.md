# Git Workflow & Commits

Sets up and enforces a clean Git workflow: branching model (GitHub Flow by default), branch naming, Conventional Commits, PR structure, .gitignore hygiene, and safe recovery recipes for common mistakes.

## Files
- `git-workflow.md` — the Git workflow skill.

## Use it when
- Starting a new repo and want good habits from commit one.
- Commit history is a mess of "fix", "wip", "changes".
- You need help writing a good commit message or PR description.
- You got into a Git mess and need a safe way out.

## Invoke
```
Use @skills/git-workflow-and-commits/git-workflow.md to set up branching and commit conventions for my repo
```
