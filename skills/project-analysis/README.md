# Project Analysis

Read-only health check of any codebase: detects the stack, maps the architecture and dependency direction, evaluates quality signals (tests, error handling, docs, dependencies, quick security pass), and delivers a scorecard report that tells you **which skill to apply next**. Nothing is ever modified.

## Files
- `project-analysis.md` — the analysis skill.

## Use it when
- You inherited or downloaded a codebase and want to understand it fast.
- Before applying any other skill to an unfamiliar project.
- You want an honest, evidence-based audit of your own project's state.

## Invoke
```
Use @skills/project-analysis/project-analysis.md and analyze this project
```

The report ends with a routing table (finding → skill), so this is the natural **entry point** to the whole skills library.
