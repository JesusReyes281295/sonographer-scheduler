# Beginner — Getting Started

For anyone who has an idea but doesn't know where to begin. Recommends ONE stack (language, database, cloud, testing tool) based on your goal and experience — no option paralysis — plus a roadmap where step 1 is achievable today.

## Files
- `beginner-guide.md` — the getting-started skill.

## Use it when
- "I want to build an app but I don't know where to start."
- You can't decide between languages, databases, or clouds.
- You want to know what you can safely IGNORE at the beginning (spoiler: Docker, Kubernetes, microservices).
