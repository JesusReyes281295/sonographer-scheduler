# Debugging & Troubleshooting

A systematic method to find the ROOT CAUSE of bugs instead of guessing: capture the facts, reproduce, isolate by binary search, state a falsifiable hypothesis, verify it, then fix — and protect the fix with a regression test.

## Files
- `systematic-debugging.md` — the debugging skill.

## Use it when
- Something fails and you don't know why.
- The bug is intermittent or "works on my machine".
- Previous "fixes" didn't stick because the real cause was never found.
