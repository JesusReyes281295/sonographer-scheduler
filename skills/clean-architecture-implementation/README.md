# Clean Architecture Implementation

Step-by-step playbooks to restructure an existing project into a clean, layered architecture — analyzing first, migrating incrementally, and keeping the build green at every step.

## Files
- `clean-architecture-backend.md` — 4-layer architecture (Domain / Application / Infrastructure / Presentation) for APIs and services.
- `clean-architecture-frontend.md` — feature-based, layered structure for SPAs (React, Angular, Vue...).

## Use it when
- Business logic lives inside controllers or components.
- The project grew and every change touches many unrelated files.
- You're starting a project and want the right structure from day one.

```
Use @skills/clean-architecture-implementation/clean-architecture-backend.md to implement clean architecture in my current project
```
