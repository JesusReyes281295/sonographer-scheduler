# Unit Testing & Coverage

Analyzes your project, recommends a testing stack (xUnit/NUnit + FluentAssertions, Vitest/Jest, pytest, JUnit...), identifies untested code by risk, and writes deterministic AAA tests. If tests already exist, it adopts your conventions instead of imposing new ones.

## Files
- `unit-testing.md` — the testing skill.

## Use it when
- Your project has no tests and you don't know where to start.
- You want to know which parts of your code are untested and risky.
- You want to raise coverage where it matters (business logic first).

## Invoke
```
Use @skills/unit-testing-and-coverage/unit-testing.md to analyze my project and add tests where they matter most
```
