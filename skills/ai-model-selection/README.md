# AI Model Selection

Helps you pick the cheapest Claude model, effort level, and thinking mode that still gets the job done — with pricing tables, decision heuristics, and a token-saving checklist.

## Files
- `model-selection.md` — the selection skill.
- `model-selection-diagram.svg` — visual decision flowchart (open in any browser): model tiers, effort ladder, and token-saving rules.

## Use it when
- You're unsure whether a task needs Haiku, Sonnet, Opus, or Fable.
- You want to reduce token spend without losing quality.
- You're deciding effort level or whether to disable thinking.

## Invoke
```
Use @skills/ai-model-selection/model-selection.md — which model and effort should I use for batch-classifying 10k support tickets?
```
