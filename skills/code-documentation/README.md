# Code Documentation

Adds concise, useful documentation to your code: XML docs / JSDoc / docstrings on public APIs, endpoint comments on controllers, and README updates — documenting the WHY and the contract, never restating the obvious.

## Files
- `code-documentation.md` — the documentation skill.

## Use it when
- Controllers/services lack any documentation.
- You need doc comments wired into Swagger/OpenAPI.
- Comments in the code are outdated or wrong and need a cleanup pass.

## Invoke
```
Use @skills/code-documentation/code-documentation.md to document all my controllers
```
